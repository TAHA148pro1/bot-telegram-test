# 🤖 ربات دانلودر تلگرام (yt-dlp)

یوتیوب، اینستاگرام، تیک‌تاک، X، فیسبوک، ردیت، ساندکلاود، ویمیو و صدها سایت دیگه.

## ویژگی‌ها
- لینک که بفرستی **فوراً** منوی کیفیت میاد؛ عنوان و حجم هر کیفیت چند ثانیه بعد روی همون منو آپدیت میشه
- کار در پیوی و گروه (توی گروه فقط لینک سایت‌های شناخته‌شده یا `/dl` روی ریپلای)
- دکمه‌های رنگی تلگرام (آبی / سبز / قرمز)
- کش file_id: لینکی که قبلاً دانلود شده، فوری ارسال میشه
- اگه حجم از حد تلگرام بیشتر بشه، خودکار کیفیت پایین‌تر امتحان میشه
- پنل ادمین `/admin`: آمار کلی، کاربران (فیلتر: امروز فعال/جدید/دانلودکننده/مسدود + جستجو)، **تاریخچه کامل لینک‌های هر کاربر با ساعت و کیفیت**، **لاگ زنده همه دانلودها**، **خروجی CSV** (هر کاربر یا کل)، مصرف ۷ روزه، پرمصرف‌ها، بن/آنبن، پیام همگانی، حالت تعمیر
- تاریخ‌ها به وقت `BOT_TZ` و به صورت شمسی (با `JALALI_DATES=0` میلادی)
- ضد کرش: هندلر خطا، ری‌استارت خودکار polling، تایم‌اوت دانلود، پاکسازی فایل موقت، ری‌استارت Railway
- هر بار استارت، yt-dlp به آخرین نسخه آپدیت میشه

## راه‌اندازی روی Railway
1. پروژه رو توی GitHub بذار و توی Railway **Deploy from GitHub** بزن (Dockerfile خودکار شناسایی میشه).
2. **Variables**: `BOT_TOKEN` و `ADMIN_IDS` (آیدی عددی خودت).
3. **Volume** بساز و روی مسیر `/app/data` مونت کن (دیتابیس اینجا ذخیره میشه).
4. فقط **۱ replica**. سرویس رو بدون دامنه/پورت بذار (worker).

## تنظیمات مهم
- **گروه**: توی BotFather → `/setprivacy` → Disable، یا بات رو ادمین گروه کن.
- **فایل تا 2GB**: از [my.telegram.org](https://my.telegram.org) ← API development tools یه `api_id` و `api_hash` بگیرین و توی Variables بذارین `TG_API_ID` و `TG_API_HASH`. Local Bot API Server داخل همین کانتینر بالا میاد (سرویس جدا لازم نیست). بار اول بات یه‌بار از سرور ابری logout میشه (عادیه). Volume روی `/app/data` حتماً باشه. بیلد اول ~۱۵-۲۰ دقیقه طول می‌کشه چون سرور کامپایل میشه.
- **لینک سایت‌های دیگه توی گروه** (Pornhub، XVideos و ~۱۸۰۰ سایت): هر لینکی که yt-dlp پشتیبانی کنه خودکار شناسایی میشه، حتی بدون `https://`. برای جواب به همه لینک‌ها: `GROUP_ALL_LINKS=1`.
- **کوکی (یوتیوب/اینستاگرام)**: یوتیوب درخواست‌های سرور (IP دیتاسنتر Railway) رو بلاک می‌کنه. راه‌حل‌ها به ترتیب:
  1. **خودکار**: بات بدون کوکی چند کلاینت مختلف یوتیوب رو پشت‌سرهم امتحان می‌کنه.
  2. **آپلود از پنل (پیشنهادی)**: `/admin` ← 🍪 کوکی‌ها ← آپلود. فایل `cookies.txt` (فرمت Netscape) رو بفرستین؛ بدون دیپلوی مجدد و فوراً فعال میشه، توی Volume می‌مونه و پیامش پاک میشه. وقتی کوکی منقضی بشه، بات خودش به ادمین خبر میده.
     نکته: کوکی رو از یه پنجره Incognito بعد از لاگین export کنین و پنجره رو ببندین؛ از یه اکانت فرعی استفاده کنین نه اکانت اصلی.
  2.5 **Cloudflare WARP رایگان (پیش‌فرض روشن)**: WARP **توی پس‌زمینه** بالا میاد و بات منتظرش نمی‌مونه؛ تا وصل نشه بات عادی استارت میشه و دانلودها مستقیم انجام میشن. وضعیت WARP (وصل/قطع) توی 🩺 تشخیص دیده میشه. با `ENABLE_WARP=0` خاموش میشه. اگه آیپی WARP بلاک بود، دوباره ری‌استارت (دیپلوی) کنین یا اکانت رو با پاک کردن پوشه `/app/data/warp` عوض کنین.
  3. **بدون کوکی (اختیاری)**: سرویس جدا روی Railway با ایمیج `brainicism/bgutil-ytdlp-pot-provider` (پورت 4416) بسازین و `POT_PROVIDER_URL=http://<service>.railway.internal:4416` رو بذارین.
  4. `COOKIES_B64` فقط وقتی استفاده میشه که هنوز کوکی‌ای آپلود نشده باشه.
- دکمه رنگی با `COLORED_BUTTONS=0` خاموش میشه.

## محدودیت‌ها
پست‌های فقط‌عکس/کاروسل اینستاگرام و محتوای خصوصی با yt-dlp پشتیبانی کامل ندارن. لایو پشتیبانی نمیشه.
سایت‌های دانلود کپی‌رایتی/محتوای دیگران رو فقط در حد قانون و استفاده شخصی استفاده کنید.

## عیب‌یابی
- در پنل ادمین دکمه **🩺 تشخیص** آیپی سرور، وضعیت WARP، وضعیت کوکی و تست واقعی یوتیوب (برای هر مسیر) و آخرین خطاها رو نشون میده.
- لاگ WARP توی Railway با پیشوند `[warp]` چاپ میشه. اگه ثبت‌نام خودکار خطا داد: روی کامپیوتر خودتون `wgcf register && wgcf generate` بزنین، فایل `wgcf-profile.conf` رو base64 کنین و توی `WG_CONF_B64` بذارین.
- کوکی: فایل `cookies.txt` یا JSON افزونه Cookie-Editor رو توی چت ادمین بفرستین (اسم فایل شامل cookie باشه)؛ خودکار ثبت و تست میشه.
